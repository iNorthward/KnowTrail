## 用途

提供实际表结构、字段和索引的查阅入口。

## 核心规则

表结构集中在 [[database/index]]；字段含义引用真实来源，业务关系和状态流转归所属业务模块。

## 数据与流程

当前没有业务表。新增结构时维护字典段落，并在相应业务 README 或专题链接到字典。

## 边界

字典不能替代业务分层。数据库引擎与交付方式由使用者决定。
