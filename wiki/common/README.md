## 用途

保存多个业务模块共同使用的概念或经验，以及尚待评估的纠正记录。

## 核心规则

只有确实跨模块共用的知识才进入本目录；稳定规范与待沉淀事项分开，不把一次纠正直接变成全局规则。

## 数据与流程

待评估记录：[[common/weekly-summary]]。以后出现公共主题时在本页按主题登记。

## 边界

公共目录不是未分类文件的收容处；能归属明确业务模块的内容回到该模块。
