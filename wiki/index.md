## 用途

按业务领域定位知识。使用方式见 [[README]]；每个业务模块维护 README 总览和子领域入口，专题按模块分组登记，不把所有 Markdown 平铺为文件清单。

## 业务模块

当前没有实际业务内容。由使用者按项目领域新增模块，每个模块独立分组，并列出模块 README、子领域及专题。

登记格式：三级标题写实际模块名，下面放“文档 / 类型 / 内容”表；目录和 module 字段跟随该业务模块，不预设任何领域。
