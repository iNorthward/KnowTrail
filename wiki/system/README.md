## 用途

保存实际项目的系统架构和跨业务技术知识，例如经确认的鉴权机制、配置体系或基础设施约定。

## 核心规则

只有真实的跨领域主题才放本目录；某项业务自己的机制仍归该业务模块。Agent 的开任务、审计、交付步骤在 workflow/guides/。

## 数据与流程

当前只有本目录说明，没有项目系统事实。产生真实主题后，在本页按技术子领域增加入口，并同步总索引。

## 边界

本目录不规定使用者的框架或数据库；不自动把所有难分类文档放进 system。
