# 工作流看板

看板用于查阅任务流程、规则加载条件、检查顺序和源码依据。点击流程中的阶段，下方会显示该阶段的动作、预期产出和主要参考资料；这些说明不代表 Agent 已经执行过该步骤。

## 启动与访问

在项目根目录运行：

```bash
python3 workflow/dashboard/serve.py
```

服务默认使用系统分配的空闲端口，请打开终端输出的看板地址。服务运行期间，点击“更新看板”可重新生成规则与脚本快照；成功后提供校对提示词，用于让 Agent 核对流程说明与当前规则是否一致。

需要固定端口时，可用 `--port 18765` 指定一个未被占用的端口。按 Ctrl+C 关闭服务。

## 离线阅读与更新

直接打开 [index.html](index.html) 可阅读最近生成的内容。离线页面的更新需要启动本地服务，或在项目根目录运行：

```bash
bash workflow/dashboard/update.sh
```

命令完成后会输出校对提示词。快照更新与说明校对是两个步骤：生成器读取当前文件，流程说明由 Agent 对照规则维护。

## 内容与运行范围

服务仅监听本机，提供页面读取与快照更新。更新操作不执行项目构建、门禁或 Git 操作。

源码快照按生成器清单收集，不包含 local 私有规则。分享页面前需核对快照中的项目内容；看板是流程参考资料，不是任务执行报告。
