# 版本 SQL 交付模板

这是一种可选格式示例，默认不启用。仅使用者选择该格式并启用 version-sql 后，以下条款才适用。版本分支为 x.y.z；功能分支通过 WORKFLOW_TARGET_VERSION 指明目标版本，不推断最大目录。实际 SQL 产生在 workflow/config.json 的 version_dir 下；本体不附带待执行 SQL。

```sql
-- 【正向变更】
-- 填经审阅的 plain SQL。

-- 【回滚脚本】
-- 独立批次，按正向相反顺序恢复。
```

同文件必须有两段；禁止动态 SQL、元数据守卫和存储过程包装。旧目录冻结，原样继承需可验证的来源。结构变化更新 wiki/database/index.md 中对应的逻辑库.表名段落；多库文件使用库名命名。

数据库账号、授权和执行动作不属于此模板。已有迁移工具的工程使用实际约定，不默认替换。
